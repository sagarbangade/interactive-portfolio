An award-winning, luxury developer portfolio featuring an ultra-smooth 60 FPS HTML5 canvas cursor-tracking character animation, an interactive Cybernetic Architecture Console, Web Audio synthesizer, and live production telemetry.

## ⚡ Key Highlights & Features

- **60 FPS Cursor-Tracking 3D Head Engine**: HTML5 Canvas rendering 64 pre-extracted WebP directional frames with shortest-path angular lerp, zero lag, and live eye-contact detection.
- **Ambient Cyber Matrix Canvas**: Dynamic particle constellation reacting to mouse coordinates across the entire viewport.
- **Interactive Career Architecture Console**:
  - **InspironLabs**: Micro-Frontend Module Federation visualizer with interactive host & remote nodes + live bus data packet simulation.
  - **ImmverseAI Innovations**: Neural NLP transformer & token stream pipeline simulator.
  - **Asterisc Technocrat**: Enterprise ORM & high-throughput relational transaction ledger.
- **Bento Engineering Labs**: 3D tilt-interactive project showcases with production telemetry dials.
- **Interactive Skill Radar**: Filterable technology matrix with live telemetry inspector.
- **Interactive Developer REPL**: Built-in zsh-style terminal in the Diagnostics section for quick system audits.
- **Web Audio API Sound Synthesizer**: Subtle, futuristic audio feedback with top-bar equalizer controls.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sagarbangade/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/`.

### Build for Production

```bash
npm run build
```
